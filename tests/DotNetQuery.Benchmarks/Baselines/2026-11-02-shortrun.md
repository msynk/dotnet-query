## Reading the numbers

- **Cache hit** (fresh data, no fetch): ~140 ns and 432 B. A cold fetch or forced refetch costs ~1.5-1.9 us of
  engine overhead on top of the fetcher itself.
- **Deduplication**: 32 concurrent callers share one fetch for ~73 us total (dominated by task scheduling).
- **Notifications**: ~22 ns per additional plain observer per change.
- **Selectors** cost ~17 ns more per observer per change than plain observers (they project every change so
  `CurrentState` stays current) but raise no notification when the selected value is unchanged - the win is
  the UI work (re-renders) they avoid, which this micro-benchmark's no-op handler does not model.
- **Structural sharing** adds ~11 us per refetch of a 1,000-record list (deep comparison). Enable it where
  stable references save more downstream work than that.
- **Transactions**: 4 keys in one atomic commit cost ~1.5x four separate atomic updates.
- **Footprint**: ~1 KB allocated per cached query (key, entry, state) in this setup.
